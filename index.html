In-Memory Boolean Logic Computation in Binary Neural Network Inspired Memristor Crossbar Array

M. A. S. Chowdhury and O. Hassan. 10th IEEE Electron Devices Technology & Manufacturing Conference (EDTM), Penang, Malaysia, 2026, pp. 1–3. Poster presented on March 3, 2026.

DOI: 10.1109/EDTM65772.2026.11497945 Download paper (PDF)
Abstract

Neural network hardware is often implemented using memristor crossbars for their non-volatility, high density, and parallel computation capability. This work presents a methodology for implementing single-bit logic computation within such memory array structures, using a binary neural network approach to design the gates. Each binary weight is encoded with two memristor devices, and standard CMOS drivers handle programming and readout. Circuit-level SPICE simulations show NAND and XOR gates working, and cascading them gives a working full adder. Any Boolean function can be implemented with this methodology.

How a NAND gate works in the array

The weights for a 2-input NAND are [−1, −1] with a bias of +1. Each weight becomes a pair of memristors: −1 is (high, low) and +1 is (low, high). Switch the inputs to see which cells conduct and how the comparator decides the output.

  • Memristors are programmed row by row with a half-bias scheme: 0 V and 1.6 V set a cell, 1.6 V and 0 V reset it, and 0.8 V on either terminal holds its state.
  • In simulation, programming takes the first 12 ns. Computation starts at 20 ns, when the start signal rises to 1.1 V.
  • XOR needs a hidden layer of two neurons. The full adder cascades two XOR circuits for the sum and uses a structure like the XOR hidden-output crossbar for the carry.
